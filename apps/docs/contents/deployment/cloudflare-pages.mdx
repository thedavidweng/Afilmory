# Cloudflare Pages 部署（手动部署模式）

Afilmory 使用 **Cloudflare Pages** 托管静态画廊。为了保留 `*.pages.dev` 域名，部署采用**本地构建 + `wrangler pages deploy` 手动上传**模式（不用 GitHub 自动构建——自动构建依赖云端环境变量/配置文件，容易产出空站）。

## Prerequisites

- Cloudflare account（免费版即可）
- 照片源：任意受支持的 [Storage Provider](/storage/providers)，推荐 **GitHub Storage**（免费、全球 CDN）
- 本机安装 `wrangler` 并完成 `wrangler login`

## 1. 配置 Storage Provider（GitHub 示例）

创建项目根目录下的 `builder.config.ts`（该文件已被 gitignore，不会提交）：

```typescript
import { defineBuilderConfig } from '@afilmory/builder'

export default defineBuilderConfig(() => ({
  storage: {
    provider: 'github',
    owner: 'your-username',
    repo: 'photo-assets', // 照片仓库
    branch: 'main',
    path: 'public/photos', // 照片目录
    useRawUrl: true, // 通过 raw.githubusercontent.com 提供原图
    token: process.env.GIT_TOKEN, // 可选，公开仓库只读不需要；建议设置以避免 API 限流
  },
  system: {
    processing: { defaultConcurrency: 10, enableLivePhotoDetection: true },
    observability: {
      showProgress: true,
      showDetailedStats: true,
      logging: { verbose: false, level: 'info', outputToFile: false },
    },
  },
  plugins: [],
}))
```

> 照片支持直接存放 AVIF 格式（`SUPPORTED_FORMATS` 已包含 `.avif`）。原图体积小、支持 EXIF，适合 GitHub 存储。

## 2. 构建 & 部署

```bash
# 构建 manifest（下载原图、生成缩略图与元数据），并构建 SPA，最后部署到 Pages
pnpm --filter=@afilmory/web deploy:cloudflare
```

等价于：

```bash
pnpm run build:manifest   # 生成 apps/web/public/thumbnails + 嵌入 dist 的 manifest
pnpm --filter web build   # 构建 apps/web/dist
cd apps/web && wrangler pages deploy  # 手动部署到 Pages 项目（wrangler.jsonc 里的 name）
```

`apps/web/wrangler.jsonc` 指向 Pages 项目：

```jsonc
{
  "$schema": "node_modules/wrangler/config-schema.json",
  "name": "afilmory", // 必须与 Cloudflare 上的 Pages 项目名一致
  "compatibility_date": "2025-06-05",
  "pages_build_output_dir": "./dist"
}
```

- 构建产物自包含：manifest 通过 `window.__MANIFEST__` 注入 HTML，缩略图位于 `/thumbnails/`，OG 图片由构建期插件生成
- `_routes.json` 的 exclude 列表让 `/thumbnails/*`、静态资源直接走静态服务，其余路径由 SPA 兜底

## 3. 关闭 GitHub 自动构建（重要）

如果 Pages 项目之前接了 GitHub 自动构建，必须关闭，否则每次 push 都会用默认配置（无存储凭据）重新构建并覆盖站点：

`Cloudflare Dashboard → Pages → 项目 → Settings → Builds & deployments → 关闭 Production / Preview 自动部署`

之后所有部署都通过本地 `wrangler pages deploy` 完成。

## 4. 绑定自定义域名

`Pages → 项目 → Custom domains` 添加域名（如 `gallery.example.com`），按提示添加 CNAME 记录，Cloudflare 自动签发 SSL。

## 5. 限流与排障

- **GitHub API 403**：未认证 60 次/小时。设置 `GIT_TOKEN`（fine-grained PAT，`Contents: Read` 权限即可）后为 5000 次/小时
- **部署后无照片**：检查 `apps/web/dist/index.html` 是否包含 `window.__MANIFEST__`，以及缩略图是否在 `dist/thumbnails/`；新部署几分钟内被 CDN 缓存属正常，带 `?cb=1` 重试即可
- **构建失败**：确认 `builder.config.ts` 中仓库/分支/路径正确

## 与 SSR 的取舍

SPA 静态部署不包含 `ssr`（Next.js）的动态能力：OG 图片与 SEO 标签在构建期生成（`og-image-storage` 插件），无法按请求实时生成。需要实时 OG/SSR 时请使用 `ssr` 应用或 SaaS 模式（`be/apps/core` 自带静态托管）。
